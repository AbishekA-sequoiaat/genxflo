Nextflow Integrations

Nextflow is one of the most powerful workflow engines in life sciences, and GenXflo offers deep integration with its DSL2 framework. Through Nextflow integrations, users can design pipelines visually on GenXflo's drag-and-drop canvas and export them as executable Nextflow workflows.

Each exported pipeline includes:

  • Modular DSL2 process definitions
  • Channel-based data flow and dependency management
  • Resource directives (CPUs, memory, storage)
  • Linked Docker or Singularity container references

By aligning visual design with the underlying Nextflow syntax, GenXflo ensures that pipelines run seamlessly in any Nextflow Docker or cloud environment, maintaining both scientific rigor and technical reproducibility.

Benefits of Nextflow Integration

  • Full compatibility with Nextflow's modular architecture
  • Automatic syntax and dependency validation before export
  • Ready-to-run Docker or Singularity containers for each process
  • Execution across HPC, cloud, or hybrid computing environments
  • Guaranteed reproducible behavior for every pipeline run

These capabilities make GenXflo a powerful companion for teams standardizing their infrastructure on Nextflow while embracing visual, no-code design.

Docker & Containerized Execution

Containerization lies at the core of Nextflow integrations, ensuring that every pipeline step runs within a consistent, isolated environment. GenXflo fully supports Nextflow Docker and Singularity execution, embedding container references directly into exported workflow files.

Why Containerization Matters

  • Eliminates dependency conflicts between software tools
  • Provides consistent runtime environments across systems
  • Enables seamless migration from local to cloud execution
  • Makes pipelines portable and 100% reproducible

Supported Container Options

Docker:

Default option for both local and cloud execution.

Singularity:

Ideal for HPC clusters or environments where Docker is restricted.

Conda:

Lightweight alternative for environments without container support.

Key Advantages

  • Full reproducibility through pinned container tags
  • Easy integration with DockerHub, Quay.io, or private registries
  • Support for multi-container workflows and complex dependencies
  • Consistent results regardless of operating system or infrastructure

Through Nextflow Docker compatibility, GenXflo bridges the gap between code, containers, and reproducibility, enabling truly portable bioinformatics workflows.

Windows Subsystem for Linux (WSL 2)

GenXflo offers complete compatibility with Windows Subsystem for Linux 2 (WSL 2), allowing Linux-native workflows like Nextflow or Snakemake to run directly on Windows systems. This eliminates the need for separate virtual machines or remote servers.

Benefits of WSL 2 Integration

  • Direct access to Linux command-line tools and file systems
  • Native performance without virtualization overhead
  • Full compatibility with Docker Desktop and container execution
  • Ideal for Windows-based research institutions or hybrid IT environments

Researchers can now build, test, and execute pipelines on Windows with the same reliability and performance as on Linux.

macOS Integration

GenXflo also supports native macOS execution for both development and testing environments. Pipelines exported from GenXflo run seamlessly using local resources and integrate with macOS-compatible tools.

macOS Benefits

  • High-performance local execution for small-scale testing
  • Unix-based compatibility with shell environments and package managers
  • Smooth integration with Docker Desktop and Conda environments
  • Reproducible results using the same container and configuration files as on other systems

This ensures that whether you use macOS for development or production, your exported workflows maintain the same execution behavior.
